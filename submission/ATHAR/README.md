# أثر | ATHAR — الكود وقاعدة البيانات (هيلثون 2026)

نموذج تفاعلي توضيحي لـ **مركز قيادة تجربة المريض**. جميع البيانات اصطناعية وتوضيحية، ولا يوجد ربط فعلي بأنظمة المنشأة ولا تتبّع حقيقي للمريض.

## محتويات الحزمة

| المسار | الوصف |
|---|---|
| `code/index.html` | النموذج التفاعلي كاملًا (HTML + CSS + JavaScript) في ملف واحد، يعمل مباشرة في المتصفح بلا تثبيت. |
| `database/schema.sql` | مخطط قاعدة البيانات (10 جداول + view لحساب درجة الأولوية). |
| `database/seed.sql` | بيانات البذر الاصطناعية للحالات الست (أ-01 إلى أ-06). |
| `database/athar_demo.sqlite` | قاعدة بيانات SQLite جاهزة، مبنية من الملفين السابقين. |
| `database/athar_data.json` | نفس البيانات بصيغة JSON (الهيكل الذي يستخدمه الديمو داخل المتصفح). |
| `api/server.py` | خادم صغير (Python 3، مكتبة قياسية فقط) يقدّم الديمو ويعرض قاعدة البيانات كـ JSON. |

## التشغيل

**الطريقة الأبسط**: افتح `code/index.html` في أي متصفح حديث.

**مع قاعدة البيانات والواجهة البرمجية**:
```bash
python3 api/server.py
# ثم افتح http://localhost:8080
```
نقاط النهاية: `/api/cases` ، `/api/cases/A-03` ، `/api/signal-types` ، `/api/thresholds` ، `/api/departments` ، `/api/places`.

**لإعادة بناء قاعدة البيانات من الصفر**:
```bash
sqlite3 database/athar_demo.sqlite < database/schema.sql
sqlite3 database/athar_demo.sqlite < database/seed.sql
```

## مخطط قاعدة البيانات

- `departments` الأقسام · `places` نقاط الخدمة ومناطق المنشأة · `signal_types` أنواع الإشارات وأوزانها ومصادرها.
- `thresholds` العتبات التوضيحية: 40 (متوسطة)، 70 (مرتفعة)، 30 دقيقة (حد التنبيه الفوري).
- `cases` الحالة: القسم، حالة المعالجة، حالة الموافقة على الموقع، والتنبيه الفوري وسببه.
- `case_signals` الإشارات المرتبطة بكل حالة (الوزن، نشطة/تاريخية، المصدر، معرّف الدليل لمنع الاحتساب المزدوج).
- `journey_events` الخط الزمني للرحلة (الحدث، الوقت، المكان، مصدر المكان: نظام أو تحديد موقع).
- `case_updates` نتيجة التواصل والتحقق والإجراء والجهة المسندة والنتيجة وطريقة التحقق.
- `follow_up_log` سجل المتابعة · `location_pings` مسار الحركة المحاكى (بموافقة فقط).
- `v_case_scores` حساب درجة أولوية التواصل: مجموع أوزان الإشارات النشطة المؤهلة (إشارات الموقع تُحتسب فقط مع موافقة ممنوحة).

## قواعد العمل المطبقة في الكود

- التنبيه الفوري يُطلق عند تجاوز انتظار الخدمة 30 دقيقة دون انتظار تراكم النقاط، ويبقى ظاهرًا حتى يراجعه الفريق.
- الواقعة الواحدة تُحتسب مرة واحدة فقط؛ الإشارة التي انتهى شرطها تنتقل إلى السجل التاريخي.
- «لم يرد» لا يسمح بإغلاق الحالة بوصفها «تمت المعالجة»؛ و«تمت المعالجة» تتطلب وصف النتيجة وطريقة التحقق.
- الإنسان في الحلقة: النظام يقترح ويرتّب ويشرح السبب، والفريق يقرر. لا وصول إلى السجل الطبي، ولا يُستخدم لتقييم الموظفين أفرادًا.

## الخصوصية

لا تحتوي الحزمة على أي بيانات مرضى حقيقية. الحالات والأوقات والأسماء كلها أمثلة توضيحية مولَّدة لأغراض العرض.
